# PIC16F877A Firmware Development

This repository contains my **PIC16F877A firmware development programs** written in Embedded C using **MPLAB X IDE and XC8 compiler**.

The programs focus on **register-level programming**, peripheral configuration, interrupts, and communication protocols.

## 🛠️ Tools Used

* **Microcontroller:** PIC16F877A
* **Language:** Embedded C
* **IDE:** MPLAB X IDE
* **Compiler:** XC8

## 🔧 What I Implemented

* GPIO configuration and register-level control
* Memory-mapped register access
* Interrupt handling and ISR implementation
* Timer1 interrupt-based applications
* CCP PWM generation and duty-cycle control
* ADC data acquisition and voltage display
* UART communication
* I2C EEPROM and RTC communication
* SPI Master and Slave communication
* LCD interfacing

## 📂 Topics Covered

### GPIO

* Digital input and output
* Register-level GPIO configuration

### Memory Map

* Direct register address access
* Register manipulation using pointers and macros

### Interrupts

* PORTB change interrupt
* Interrupt Service Routine (ISR)

### Timer

* Timer1 configuration
* Timer1 interrupt
* Counter-based timing

### PWM

* CCP1 PWM
* PWM period configuration
* Multiple PWM duty cycles

### ADC

* ADC initialization
* 10-bit ADC data acquisition
* ADC value conversion
* LCD display

### UART

* UART initialization
* Serial data transmission
* Serial data reception
* Baud rate configuration
* Register-level UART programming

### I2C

* I2C Master
* Start, Stop and Repeated Start
* ACK/NACK
* EEPROM read/write
* RTC communication

### SPI

* SPI Master
* SPI Slave
* Data transmission and reception
* SPI interrupt

## 🎯 Objective

The objective of this repository is to build a strong understanding of **PIC16F877A firmware development and register-level Embedded C programming** through practical implementation.
